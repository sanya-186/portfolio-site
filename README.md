# 🚀 Sanya Sachdeva — Web Developer & Frontend Specialist Portfolio

A modern, interactive 3D developer portfolio showcasing the work, skills, and experience of **Sanya Sachdeva**.

---

## ✨ Key Features

- **Interactive 3D Hero:** Custom 3D room model rendered with React Three Fiber, complete with subtle camera controls and particle ring backdrop.
- **Modern Dark UI:** Sleek glassmorphic design built with Tailwind CSS, custom violet gradients, and smooth Framer Motion entrance animations.
- **Work Experience Showcase:** Dedicated timeline featuring software engineering experience at **Give X India**, with direct links to live client storefronts (*Thirty Third World*, *GoXtreme Shop*, *Give X India Portal*).
- **E-Commerce & Tech Stack:** Organized categorizations for Frontend Development, Backend, Databases, E-Commerce & CMS (Shopify), Tools & Platforms, and Dashboards & Analytics (Power BI / Excel).
- **Projects & Storefronts:** Interactive project cards with live demo links and technical stack badges.
- **Certifications & Workshops:** Credentials in Cyber Security (SRM University), Machine Learning (Atos Prayas Foundation), and Deloitte Technology Simulation (Forage).
- **Contact & Socials:** Integrated EmailJS contact form plus direct links to LinkedIn and GitHub.

---

## 🛠️ Tech Stack

- **Frontend:** React 19, Vite
- **3D Graphics:** Three.js, `@react-three/fiber`, `@react-three/drei`
- **Styling & Motion:** Tailwind CSS, Framer Motion, React Tilt, React Vertical Timeline
- **Integrations:** EmailJS, React Icons

---

## ⚡ Getting Started

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Configure environment variables (`.env`):**
   ```env
   VITE_EMAILJS_SERVICE_ID=your_service_id
   VITE_EMAILJS_TEMPLATE_ID=your_template_id
   VITE_EMAILJS_PUBLIC_KEY=your_public_key
   ```

3. **Run local development server:**
   ```bash
   npm run dev
   ```

4. **Build for production:**
   ```bash
   npm run build
   ```
